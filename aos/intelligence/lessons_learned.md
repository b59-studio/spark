# Lessons Learned

> Surprises, failures, and validated discoveries. Before starting a task, scan this file. Before ending a session, ask: did anything surprise me? If yes, add it here.
>
> The goal is that no agent rediscovers something painful that a previous agent already learned.

---

## Template

```
## YYYY-MM-DD | [Context / task name] | [Short title]

**Context:** [What were you doing when you learned this?]

**Lesson:** [The actual insight — specific enough to act on]

**Impact:** [What went wrong, or what would have gone wrong without this knowledge?]

**Recommendation:** [What should future agents do differently?]
```
